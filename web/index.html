Suki Mart is losing money and customers. Autopilot finds why, fixes it, and shows the evidence.

An operations agent built on Hermes. It diagnoses the struggling branch, moves stock, marks down food before it spoils and cancels duplicate orders. Every action is logged with the numbers behind it, and risky ones wait for a human to approve.

    How it runs

    1. Desktop pane in Hermes: Diagnose, Run Autopilot, Approve / Reject.
    2. Skill suki-autopilot chains the tools: diagnose → find → act → ledger.
    3. MCP server suki-autopilot: 10 domain tools on the Suki Mart database. It writes each ledger row before applying the change.
    4. MCP server bantay: the people and customer fixes (shift cover, ticket escalations, review replies), shown in the feed with a Bantay badge.
    5. After each action, the MCP servers mirror the ledger to Neon Postgres. This page reads it through a read-only role and refreshes every 4 seconds.
